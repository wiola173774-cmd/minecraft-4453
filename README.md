# ABSURD 1.20.1 Forge World

A deliberately ridiculous Minecraft Java Edition 1.20.1 world project.

GitHub Actions builds a Minecraft 1.20.1 world save and packages it as a ZIP artifact.

Includes giant floating islands, a colossal duck, oversized sword, lava volcano, enormous Nether portal, TNT ring, ridiculous tower, diamond vault, checkerboard terrain, and hidden nonsense.

## Build
Run the Build Minecraft World workflow, then download the Absurd_1.20.1_Forge_World artifact.

Extract the ZIP and put the resulting world folder in your Minecraft saves directory.

Minecraft: Java Edition 1.20.1
Loader: Forge 1.20.1 compatible
